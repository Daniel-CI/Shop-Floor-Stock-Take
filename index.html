How to use

  1. Racking: scan the bin barcode, then scan each pallet label.
  2. Machine or floor locations (101, 118, etc.): tap "Change", pick the location, then scan the pallets.
  3. When a location is finished, tap "Location done", including empty ones. This is how the report tells a genuinely missing pallet from one that was never checked.
  4. Go to "Report" to export the Excel file.
